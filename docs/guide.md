# 从当前问题开始

[English](guide.en.md) · [返回首页](../README.md)

安装后使用 `zane-career-assets` 即可。它直接处理任务，不需要你先认识11个工具，也不要求先创建长期档案。下面均为虚构示例。

## 旧简历先给过来

```text
这是我的旧简历，想投运营实习。请根据这份JD重做一页简历，
给我可编辑HTML，先完成候选版，我看后再修改。
```

先读取已有材料，挑出岗位相关的事实，重组内容并实际生成文件。缺少电话号码可以暂留空；缺少岗位方向会影响取材时才问。不会停在“建议你选一个版式”，也不会凭空补业绩。

你也可以指定Word、PDF或仅改正文。实际生成的格式才检查相应版式；只要简历，不会自动为你做网站。

## BOSS直聘：在线开头与打招呼分别写

假设你做过校园活动6篇推文，并整理过阅读数据，目标岗位需要选题、编辑和复盘。

```text
请分别写：在线简历个人优势的开头、个人优势全文、这个岗位的打招呼语。
开头控制在我指定的20字以内，标点也计入。附件简历不用重做。
```

可能的开头：“做过6篇校园推文，能选题、编辑和复盘”。这是按照指定预算形成的示例，不是BOSS官方字数规则。

打招呼可以连接具体岗位：“看到岗位需要选题和复盘，我做过校园活动的6篇推文，也整理过阅读数据，想和您聊聊内容运营实习。”个人优势全文再展开相关工作；不会在三个触点复制同一大段。

平台的预览截断、输入上限、附件及外链能力以当前界面为准。没有证据时不承诺固定字数、曝光加权或回复率。

```text
对方问每周能来几天。这是我的课表和可到岗时间，帮我回复。
```

后续沟通接着当前问题，不重新从头自我介绍。消息先供你使用，实际发送需要相应授权。

## 没有实习，也能做有用材料

```text
我只有课程项目和一次社团经历，想投产品或运营。
帮我比较现有经历能支持什么，先改出各自最相关的一段。
```

从真实任务、产出、反馈中取材，区分课程、社团与雇佣经历。没有数据不编造，没有业务收入不等于没有能力证据。

## 作品集以能展示的作品为起点

```text
我有两份调研报告和一个原型，想申请产品实习。
请做一个能让招聘方快速看懂的作品集，先给本地网页。
```

选择代表作，安排阅读顺序，再制作页面并检查实际显示。少量作品不强凑多篇长案例，也不必须建立知识库。若负责团队，按真实管理职责展示团队结果，不要求拆算个人贡献率。

## 面试逐轮练

```text
针对这份JD面试我。每次只问一个问题，等我回答，再追问和点评。
```

Agent提出第一个问题后等待真实回答；不会代你答完一场面试。下次继续时保留题目、你的实际回答和暂停点。笔试或作业可做练习和思路复盘，正式招聘考核按其允许的协助范围处理。

## offer放在同一口径下比较

```text
A每月12000元、固定12薪；B每月11000元、固定14薪，写着最高16薪。
其他条件相同，先比较保证税前年收入，再帮我写询问奖金条件的话。
```

保证部分分别为14.4万、15.4万元。“最高16薪”不能当保证；奖金、试用薪资、发放资格和地点成本按实际缺口核实。不会编造另一个offer作为谈判筹码。

## 保存与继续

单次任务不建状态档案。需要持续迭代时说“保存当前稿和下次继续的位置”；已有项目就沿用。事实纠正会更新受影响的材料，旧投递或旧部署作为历史保留，不假称已自动更新。
