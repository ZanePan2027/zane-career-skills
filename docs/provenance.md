# 来源与设计取舍 / Design sources

本工具箱由求职材料制作中的实际问题迭代而来，涵盖取材、招聘表达、简历排版、作品集、多语言和实际文件检查。私人简历、公司资料与真实业务数据不作为公开模板或测试输入。

2026-09-17 对照 [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill/tree/8b8e33f1ecaed8cee606fe950c4426b525ead314) 的统一入口、目标澄清与保存／恢复设计。借鉴任务驱动、按需读取、减少重复追问及恢复真实暂停点。这里直接完成当前求职任务，默认先交付可编辑候选，不要求长期开台或把路由提示词再发送一遍。

方法正文、示例和代码独立编写；没有复制、改名收录DBS的Skill。安装本工具箱不依赖DBS或其他工作台。Skill组织参考通用Agent Skills规范，不能据此推定行为质量。

BOSS公开说明的核查结论与未知见[平台依据](../skills/zane-career-assets/references/platform-evidence.md)。任务覆盖不等于求职结果保证；内部测试不证明与其他工具相比的普遍优势。

This toolkit draws on practical résumé and portfolio production problems. Its task routing and continuation design were informed by the linked public DBS revision. Instructions, examples and code were independently written; DBS Skills are not copied, renamed or required. Private candidate and employer material is not distributed. Internal checks do not establish hiring effectiveness or comparative superiority.

本版也对照人生、商业增长与职业成长三套工具的共同优点：当前任务优先、按需读取原始材料、已有事实不重复追问、完成实际成果、事实纠正传到相关版本、保存真实暂停点、区分草稿与实际动作。只在求职任务有用的位置吸收；不引入长期建台要求，不依赖其他套装，也不复制它们的专业模块。
