# 安装与使用

## 安装

```bash
npx -y skills add ZanePan2027/zane-career-skills -g --all
```

这会安装完整求职工具箱。按 Agent 要求重载 Skills 后，使用 `zane-career-assets` 开始。

只在当前项目使用时，省略 `-g`。也可以让 Agent 从 [GitHub 仓库](https://github.com/ZanePan2027/zane-career-skills)安装全部 Skills；具体位置按宿主的安装规则处理。

## 开始使用

告诉 Agent 当前要完成的事，附上相关经历、作品或岗位说明。可以先整理一段课程经历、比较两个岗位、做一份简历，或练习一场面试。

## 更新

让 Agent 比较当前安装版与仓库最新版，保留本地修改后更新。公开调用名统一为 `zane-*`。个人经历和求职成果保存在自己的项目文件夹中。

## 版本安装

在 GitHub 的 Tags 中选择 `v1.0.0`，让 Agent 安装该标签的内容。

旧版见仓库 [Releases](https://github.com/ZanePan2027/zane-career-skills/releases)。
