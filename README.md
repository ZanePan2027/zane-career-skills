**AI 求职工具箱。给正在从校园走向职场，也在毕业后重新认识自己的年轻人。**

从课程、社团、实习和工作经历中找到能说明能力的材料，对照岗位形成求职方向，完成多语言简历、作品集和面试表达。经历逐渐丰富时，同一套方法也可以继续用于跳槽和职业转向。

**适用于 Claude Code、Codex，以及其他支持 Agent Skills 的工具。免费开源。**

## 快速开始

### 1. 安装

在终端执行：

```bash
npx -y skills add ZanePan2027/zane-career-skills -g --all
```

也可以直接告诉 Agent：

```text
请从 https://github.com/ZanePan2027/zane-career-skills 安装全部 Skills，
然后使用 zane-career-assets，帮我处理这件事：……
```

按安装界面选择使用的 Agent，完成后按宿主要求重载。命令安装需要 Node.js 和 `npx`；项目级安装与更新见[安装说明](docs/install.md)。

### 2. 说出当前问题

```text
请使用 zane-career-assets。
我正在准备第一份工作，做过一个课程项目，也负责过社团活动报名和签到。
这是我的项目报告和经历说明，请帮我找出能写进简历的内容，
并对照这两个岗位，看看各自需要突出哪些经历。
```

这次可以先得到：可用经历、本人贡献、需要补充的事实，以及针对岗位的简历条目。已有简历或岗位说明时直接提供；还没有整理完整，也可以先讲一件做过的事。

### 3. 接着制作或练习

```text
先把这段经历写成简历条目。
再围绕它模拟一次面试，每次问一个问题，等我回答后再继续。
```

需要整份简历、作品集或网站时，再说明岗位、语言和要拿到的文件。只做一项任务，也可以从这个入口开始。

## 可以处理的事

| 你可以这样说 | 可以得到 |
| --- | --- |
| 没有实习，课程项目能写进简历吗？ | 本人动作、作品证据和适合放进简历的条目 |
| 这两个岗位，我的经历分别能支持什么？ | 岗位要求与经历的对照、优势和待补证据 |
| 我有旧简历，想申请英文岗位 | 根据目标市场和岗位重写的简历内容及版式 |
| 面试讲项目时总像在念流水账 | 清楚的项目回答，以及逐轮追问和修改 |
| 项目是团队做的，我该怎样写自己的贡献？ | 本人动作与团队结果的区分、可支持的表达 |
| 想用作品集展示项目 | 阅读结构、案例内容和网站实现 |

## 从经历到求职材料

先从你提供的经历中整理事实与证据，再对照岗位决定突出什么。简历、作品集、投递消息与面试回答使用同一份经历依据。

在同一项目继续修改时，把新事实或招聘反馈带回来。Agent 会检查它影响了哪些材料，更新相关内容并说明改了哪里。需要制作Word、PDF或网站时，文件生成与检查使用当前宿主可用的工具。

[看完整示例：一段社团经历怎样进入简历和面试](docs/guide.md)

## 怎样继续上次的任务

成果保存在你选择的项目文件夹中。暂停时可以说：“保存这次采用的版本、待确认的事实和下一步。”下次提供这个文件夹，说明继续哪份岗位申请或哪场面试练习。

若当前聊天不能读写文件，保存一份接续摘要，下次与必要材料一起提供。

## 按具体任务使用

日常从 `zane-career-assets` 进入。熟悉后，可以直接选择简历、作品集、案例、投递消息或交付检查等方法；[能力目录](docs/skill-inventory.md)列出11个入口的适用场景、输入示例和产出。

## 与过好你的人生怎样选择

对照岗位整理经历、制作求职材料和练习面试，从这里开始。若选择还涉及家庭安排、收支、生活地点和个人方向，可以使用[过好你的人生](https://github.com/ZanePan2027/zane-life-workbench)放在一起比较。两套工具都可独立使用。
